JeffOffice for Debian and Ubuntu

JeffOffice is a free, open-source office suite: JeffPub, JeffDeck, JeffWrite, and JeffCrunch. Add this repository once, and apt installs it and keeps it up to date. The current version is 0.10.3. It needs Ubuntu 22.04 or newer, or Debian 12 or newer, on a 64-bit Intel or AMD computer (amd64). The download is about 100 MB (about 320 MB once installed). This repository serves the newest version only.

Add the repository

sudo apt install wget    # skip this if wget is already installed
sudo install -d -m 0755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/jeffoffice.gpg https://jeffoffice.github.io/apt/jeffoffice.gpg
sudo wget -O /etc/apt/sources.list.d/jeffoffice.sources https://jeffoffice.github.io/apt/jeffoffice.sources
sudo apt update

Install JeffOffice

sudo apt install jeffoffice

Later versions arrive with your other updates (sudo apt update && sudo apt upgrade).

What the files are

  • jeffoffice.gpg: the public key that signs this repository, as a binary keyring (jeffoffice.asc is the same key as text). Its fingerprint is 141F304F0AD9E63EDB9D444463DAA97BACDF2F2A.
  • jeffoffice.sources: the repository entry. It says that only this key may vouch for these packages.

Remove it

sudo apt remove jeffoffice
sudo rm /etc/apt/sources.list.d/jeffoffice.sources /etc/apt/keyrings/jeffoffice.gpg
sudo apt update
